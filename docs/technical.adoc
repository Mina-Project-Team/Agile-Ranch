= Środowisko deweloperskie — uruchomienie i konfiguracja

== Wymagania wstępne

- Git 2.30+
- Node.js 16+ (jeśli frontend używa narzędzi webowych)
- Java 11+ / Python 3.10+ (w zależności od stacka backend)

== Szybkie uruchomienie (developer)

.Klonowanie repozytorium
----
git clone https://github.com/Mina-Project-Team/Agile-Ranch.git
cd Agile-Ranch
----

.Uruchomienie środowiska lokalnego (przykład dla Node)
----
npm install
npm run dev
----

== Struktura katalogów (wybrane)

- `docs/` — dokumentacja AsciiDoc
- `game-engine/` — logika gry (biblioteka)
- `frontend/` — aplikacja kliencka
- `backend/` — serwisy API
