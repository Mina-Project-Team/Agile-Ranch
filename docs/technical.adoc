= Development Environment - Setup and Run

== Prerequisites

- Git 2.30+
- Node.js 16+ (if the frontend uses web tooling)
- Java 11+ / Python 3.10+ (depending on the backend stack)

== Quick Start (Developer)

.Clone the repository
----
git clone https://github.com/Mina-Project-Team/Agile-Ranch.git
cd Agile-Ranch
----

.Start the local environment (Node example)
----
npm install
npm run dev
----

== Directory Structure (selected)

- `docs/` - AsciiDoc documentation
- `src/` - Python game engine implementation
- `tests/` - pytest-based unit tests
